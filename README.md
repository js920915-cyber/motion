# R스포츠재활센터 브랜드 소개 모션그래픽 프롬프트

R스포츠재활센터의 브랜드 철학과 전문성을 전달하는 30초 분량의 브랜드 소개 모션그래픽을 제작해줘.

전체 메시지는 **단순한 통증 감소를 넘어, 객관적인 평가와 체계적인 재활을 통해 일상 및 스포츠 복귀와 퍼포먼스 향상을 돕는 전문 스포츠재활센터**라는 방향으로 구성해줘.

## 01. BRAND PHILOSOPHY | 브랜드 철학

**통증이 줄었다고, 회복이 끝난 것은 아닙니다.**

우리는 통증 감소를 넘어 신체 기능의 회복과 더 나은 움직임을 추구합니다.

## 02. ASSESSMENT | 객관적인 평가

**정확한 재활의 시작은 객관적인 평가입니다.**

근력, 움직임, 신체 기능을 다각도로 평가하여 현재의 상태를 파악합니다.

## 03. DATA ANALYSIS | 데이터 기반 분석

**눈에 보이지 않는 차이까지, 데이터로 확인합니다.**

첨단 측정 장비와 움직임 분석을 통해 개인의 강점과 부족한 부분을 파악합니다.

## 04. REHABILITATION | 맞춤형 재활

**같은 부상이라도, 필요한 재활은 다릅니다.**

개인의 신체 기능과 회복 단계, 목표에 맞춰 체계적인 재활 프로그램을 설계합니다.

## 05. RETURN TO ACTIVITY | 일상 및 스포츠 복귀

**회복의 목표는 다시 움직이는 것입니다.**

일상 복귀부터 스포츠 현장 복귀까지, 단계적인 훈련을 통해 필요한 신체 능력을 준비합니다.

## 06. PERFORMANCE | 퍼포먼스 향상

**재활의 끝이 아닌, 더 나은 움직임의 시작.**

부상 관리부터 근력, 파워, 움직임 능력 향상까지 개인의 가능성을 확장합니다.

## 07. BRAND IDENTITY | 브랜드 메시지

**회복을 넘어, 더 나은 움직임으로.**

평가부터 재활, 스포츠 복귀와 퍼포먼스 향상까지.
