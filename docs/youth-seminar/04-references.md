## 우리 릴스에 적용할 점 (현재 버전과 비교)

1. **강사(전문가) 공개 컷이 없다** → 거의 모든 레퍼런스가 "누가 알려주는지"를 보여줌. 강사 이름·직함 + 한마디 컷 추가 필요(정보 필요).
2. **대상이 마지막에만 나온다** → 첫 2초 안에 "학부모·지도자님께".
3. **영상 속 '작은 팁'** → MasterClass식으로 관절 조준 컷에 실제 체크 포인트 한 문장.
4. **한 편이 아니라 시리즈** → 테마 3종을 고르는 대신 공지 → 주제 3편 → 강사 공개 → D-7/D-1 카운트다운으로 나눠 쓰기.
5. **얼굴 나오는 한 문장** → 강사가 카메라 보고 말하는 3초 영상이 있으면 그래픽보다 신뢰도가 높음.
