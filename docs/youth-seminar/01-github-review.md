### Remocn에서 골라 둔 컴포넌트 (모두 `remotion`만 의존, 외부 엔진 불필요)

| 컴포넌트 | 원래 연출 | 릴스에서의 용도 |
|---|---|---|
| `shot-clock` | 경기 샷클락 카운트다운 → 버저 | 오프닝 훅: 카운트다운 후 "왜 맨날 다칠까요?" |
| `score-bug` | 중계 화면 스코어 박스 | 축구 중계 그래픽 톤으로 "부상 원인 / 성장기 / 움직임" 3포인트 |
| `impact-shake` | 묵직한 글자 낙하 + 카메라 흔들림 + RGB 분리 | 훅 문장/"부상" 키워드 강조 |
| `strobe-words` | 리듬에 맞춰 큰 단어 점멸 → 로고 | 비트싱크 키워드 몽타주 (기존 BPM 체계와 그대로 연결) |
| `speed-lines` | 속도선 + 스쿼시 착지 | 드리블 영상 위 움직임 강조 |
| `bracket-focus` / `crosshair-lock` | 뷰파인더 브래킷·조준 | 기존 HUD 브래킷과 같은 언어 → 영상 속 무릎/발목 포커스 |
| `rsvp` | What/When/Where 표 + 신청 | 엔딩: 일시·장소·대상·QR 접수 |
| `halftone-cut` | 하프톤 도트로 제목 전환 | 기존 `Halftone`과 같은 계열 전환 |

> 폰트는 모두 Google Fonts를 불러오도록 되어 있어, 복사할 때 우리 `SANS`/`MONO`(Pretendard/JetBrains Mono)와 `theme.ts` 색으로 교체합니다.
